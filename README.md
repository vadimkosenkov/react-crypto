# 📈 React Crypto Tracker

A modern Single Page Application (SPA) for tracking cryptocurrency market data and managing a personal investment portfolio. The application provides real-time market information, historical price analytics, and portfolio performance tracking with persistent local storage support.

🔗 Live Demo: https://react-crypto-tracker-b274b1.netlify.app/

🔗 Repository: https://github.com/vadimkosenkov/react-crypto

## 🚀 Key Features

- Browse cryptocurrencies with pagination and detailed asset pages.
- Build and manage a personal crypto portfolio.
- Analyze historical price data through interactive charts.
- Track portfolio profit/loss based on current market prices.
- Persistent portfolio storage via Local Storage.
- Fully responsive design for desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Redux Thunk (createAsyncThunk)
- React Router DOM
- Bootstrap 5
- SCSS (Sass)
- BEM Methodology

## 🌐 Data & Visualization

- **CoinCap API** — real-time cryptocurrency market data, asset details, and historical price information.

- **Recharts** — interactive and responsive charts for cryptocurrency price history visualization.

## ⚙️ Quick Start

### 1. Clone the repository

bash git clone https://github.com/vadimkosenkov/react-crypto.git cd react-crypto 
```bash
git clone https://github.com/vadimkosenkov/react-crypto.git
cd react-crypto
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
``` 

The application will be available at:

```text
http://localhost:3000
```
